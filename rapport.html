3. Description de la conception

Architecture

L'application suit une architecture client-serveur avec Flask comme framework backend et PostgreSQL comme base de données.

Structure du projet

PIL1_2526_12/
├── app/
│   ├── routes/
│   │   ├── auth.py        (inscription, connexion)
│   │   ├── matching.py    (algorithme de matching)
│   │   ├── profil.py      (gestion des profils)
│   │   └── messagerie.py  (messagerie)
│   ├── templates/         (pages HTML)
│   ├── static/            (CSS, JS)
│   └── matching.py        (algorithme de matching)
├── schema.sql             (structure BDD)
├── seed.sql               (données de test)
└── run.py                 (lancement)

4. Instructions de déploiement

  1. Cloner le dépôt : git clone https://github.com/miracleabh-oss/PIL1_2526_12.git
  2. Installer les dépendances : pip install flask psycopg2
  3. Créer la base de données : psql -U postgres -c "CREATE DATABASE mentorlink"
  4. Charger le schéma : psql -U postgres -d mentorlink -f schema.sql
  5. Charger les données de test : psql -U postgres -d mentorlink -f seed.sql
  6. Lancer l'application : python run.py
  7. Ouvrir : http://127.0.0.1:5000

5. Manuel d'utilisation

  1. Aller sur la page d'accueil
  2. Cliquer sur S'inscrire et remplir le formulaire
  3. Se connecter avec son email et mot de passe
  4. Consulter son profil et modifier ses compétences et disponibilités
  5. Consulter les résultats de matching pour trouver un mentor ou mentoré
  6. Envoyer un message via la messagerie intégrée
